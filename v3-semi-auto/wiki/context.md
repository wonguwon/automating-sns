# Context

## 프로젝트 목적

SNS 콘텐츠(카드뉴스·릴스) 제작 파이프라인을 자동화하는 프로젝트. 소재 수집부터 딥리서치, 콘텐츠 생성, 렌더링, 캡션 작성까지의 흐름을 다룬다.

## 버전 관계

- **V1**: 최초 구현 버전.
- **V2**: V1 이후 고도화 및 트러블슈팅이 반영된 버전. 완전 자동화 파이프라인 구조.
- **V3**: 완전 자동화의 한계를 반영해 새롭게 설계할 반자동화 버전. 이 저장소가 V3다.
- V1, V2는 과거 스냅샷으로 보존하고 더 이상 변경하지 않는다.
- 현재 개발 대상은 V3뿐이다.

## 현재 상태

- V3 코드는 V2를 그대로 복제한 상태다.
- V3 고유의 설계(무엇을 자동화하고 무엇을 사람이 개입시킬지)는 아직 확정되지 않았다.
- data 폴더와 기존 실행 기록(history 등)은 아직 손대지 않았다.

## 현재 확정된 원칙

- 자세한 확정 사항은 [decisions.md](decisions.md) 참조.

## 아직 결정하지 않은 사항

- V3에서 완전 자동화 대신 반자동화로 바꿀 구체적 지점(어느 단계에 사람이 개입하는지).
- 기존 V2 기능(RSS 수집, 딥리서치, 렌더링, 캡션 생성 등)의 유지/단순화/제거/보류 여부.
- data 폴더 구조, history 중복 판정 방식의 변경 여부.
- 새로운 기술 스택이나 의존성 도입 여부.
