# Decisions

이 문서는 장기적으로 유지될 확정 결정만 기록한다. 임시 아이디어나 검토 중인 옵션은 여기 적지 않는다.

## 확정된 결정

- V1과 V2는 과거 스냅샷으로 보존한다. 더 이상 수정하지 않는다.
- 신규 개발은 V3(`v3-semi-auto`, 이 저장소)에서 수행한다.
- V3는 완전 자동화가 아닌 반자동화 방향으로 새롭게 설계한다.
- V3는 V2 코드를 출발점(복제본)으로 사용한다.
- V3 설계가 확정되기 전에는 기존 `data` 폴더와 history 기록을 변경하지 않는다.
- 위키(`wiki/`)에는 장기적으로 유지될 사실과 결정만 기록한다. 새로운 기술 선택이나 기능 유지 여부는 실제로 결정된 뒤에만 여기 추가한다.
- V3는 파이프라인을 순차 "단계" UI가 아니라, 문서(파일) 기반으로 각 단계를 독립 실행 가능하게 재설계한다. `data/pipeline/<content_id>.json` 매니페스트가 단계 간 연결 문서 역할을 한다(2026-07-28).
- 소스(피드) 관리는 그룹 단위(`sources/*.json`)로 한다. 그룹 생성 시 GPT로 피드 후보를 자동 제안받고 헬스체크로 실제 URL 여부를 검증할 수 있다(2026-07-28).
- history.json 기록은 데이터 구조가 재설계될 때까지 임시로 끈다 — 어차피 구조를 다시 잡을 예정이라 지금 형태로 계속 기록하지 않는다(2026-07-28, 5단계 콘텐츠 렌더 페이지에 적용).

## 아직 확정되지 않은 것 (여기 적지 않음)

- 구체적인 기술 스택, 라이브러리, 아키텍처 선택
- 기존 기능별 유지/제거 여부
- V3의 반자동화 흐름 세부 설계

이 항목들은 결정되는 즉시 위 "확정된 결정" 목록에 추가한다.
