# wiki/sources

이 폴더는 V1·V2 교안, 과거 설계 문서, 트러블슈팅 기록 등 필요할 때만 찾아보는 참고자료를 보관한다.

- `wiki/context.md`, `wiki/decisions.md`, `wiki/roadmap.md`와 달리, 이 폴더의 문서는 매 작업 시작 시 읽지 않는다.
- 과거 버전(V1, V2)의 배경이나 특정 트러블슈팅 이력을 확인해야 할 때만 참조한다.
- 여기 있는 내용은 과거 시점의 기록이며, 현재 V3의 확정 사실이 아니다. 현재 상태 판단은 `wiki/context.md`와 `wiki/decisions.md`를 따른다.
