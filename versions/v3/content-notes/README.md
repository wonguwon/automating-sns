# content-notes

이 폴더는 `wiki/`와 목적이 다르다.

- **wiki/**: 다음 개발 세션을 위한 현재 사실과 결정을 담는다. 항상 최신 상태를 유지하고, 오래된 내용은 갱신하거나 제거한다.
- **content-notes/**: 강의, 유튜브, SNS 콘텐츠 소재로 쓸 시행착오와 이야기를 담는다. 실패 경험, 삽질, 의사결정 배경처럼 시간이 지나도 콘텐츠 소재로서 가치가 있는 기록을 남긴다. 오래돼도 지우지 않고 쌓아둔다.

작업 중 흥미로운 시행착오나 배울 점이 있는 실패/성공 경험이 생기면 이 폴더에 기록을 남긴다.
