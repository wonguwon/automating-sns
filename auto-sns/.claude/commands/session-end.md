# 세션 종료

이 커맨드는 확인과 제안까지만 한다. 사용자가 명시적으로 승인하기 전에는 어떤 문서도 수정하지 않는다.

## 할 일

1. `git status`와 `git diff`로 이번 세션에서 실제로 변경된 파일을 확인한다. 대화 중 언급했던 내용이 아니라 실제 diff를 기준으로 삼는다.
2. 이번 세션에서 실제로 실행하거나 테스트한 것과, 하지 않은 것을 구분해 보고한다. 실행하지 않은 테스트를 통과했다고 말하지 않는다.
3. 아래 여섯 항목을 각각 **갱신 필요 / 불필요**로 분류하고, 항목마다 이유를 한 줄로 붙인다.
   - **A: `wiki/context.md`**
   - **B: `wiki/current.md`**
   - **C: `wiki/decisions.md`**
   - **D: `wiki/roadmap.md`**
   - **E: `wiki/retrospective.md`** — 큰 접근 실패, 검증된 교훈, 방향 전환에 필요한 내용이 있을 때만 "갱신 필요"로 제안한다. 일반적인 세션에서는 "불필요"가 기본값이다.
   - **F: `wiki/work-log.md`** — 날짜별 짧은 작업 기록이 필요할 때만 "갱신 필요"로 제안한다.
   - **G: 위키 갱신 없음** — A~F가 모두 불필요하면 이 항목만 표시한다.
4. "갱신 필요"로 분류한 항목에 대해서는 구체적으로 어떤 내용을 추가/수정할지 초안 형태로 제시한다 (아직 파일에 쓰지는 않는다).
5. 사용자가 승인한 항목만 실제로 수정한다. 승인받지 않은 항목은 그대로 둔다.

## 최종 보고 형식 (CLAUDE.md 종료 시 보고 항목)

- 변경한 파일
- 실제 검증 결과 (무엇을 실행/테스트했는지, 하지 않았다면 그것도 명시)
- 갱신한 위키 문서와 갱신 이유 (승인받아 실제로 수정한 경우에만)
- 확인하지 못한 사항

## 제약

- 사용자 승인 전에는 A~F 어느 문서도 수정하지 않는다.
- API 키와 환경변수 값을 보고에 노출하지 않는다.
